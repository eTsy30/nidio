# Базовые компоненты Nidio

Живые примеры: `/ui-kit`. Цвета и тени берём из `shared/styles/tokens.css`.

| Назначение                            | Компонент                                                                               | Использование                                                                                    |
| ------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Действия                              | `Button`                                                                                | `primary`, `secondary`, `ghost`, `destructive`, `link`, `icon`; загрузка через `loading`         |
| Ячейки и сложные интерактивные строки | `Button variant="plain" size="none"`                                                    | Сохраняет нативную кнопку, фокус и disabled; раскладку задаёт предметный компонент               |
| Переключаемый выбор                   | `ChoiceButton`                                                                          | `selected` задаёт оформление и `aria-pressed`                                                    |
| Поле с подписью и сообщением          | `Input`, `PasswordInput`                                                                | Для обычных форм; передавать `label`                                                             |
| Поле внутри существующей подписи      | `InputControl`                                                                          | Без дополнительной обёртки; поддерживает ref, дату, время, checkbox и radio                      |
| Многострочный текст                   | `Textarea`                                                                              | Подпись через `<label>` или `aria-label`; сохраняет стандартные атрибуты формы                   |
| Выбор из списка                       | `Select`                                                                                | Нативный выбор на телефоне, единая стрелка, `label` или внешняя подпись; ref для React Hook Form |
| Флажок и радиогруппа                  | `Checkbox`, `RadioGroup`, `RadioGroupItem`                                              | Для управляемых форм и групп выбора                                                              |
| Карточки                              | `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`       | `asChild` сохраняет семантический `section`; не заменяет контейнеры раскладки                    |
| Диалоги                               | `Dialog` и его части                                                                    | Общие фокус, Escape, фон, закрытие и прокрутка                                                   |
| Даты                                  | `Calendar`                                                                              | Общий выбор даты; месячный/недельный/годовой экран с событиями остаётся предметным компонентом   |
| Остальные элементы                    | `Badge`, `Link`, `Avatar`, `AvatarPair`, `ScrollArea`, `ContextMenu`, `DataUnavailable` | Переиспользовать существующие реализации из этой папки                                           |

`button.tsx` — совместимый реэкспорт основной кнопки, а не вторая реализация.
У кнопок с одной иконкой обязательна доступная подпись (`aria-label`).
Для обычного действия не использовать `plain`, чтобы не копировать оформление кнопок на экраны.
Сохранять `name`, `ref`, `type`, валидацию и обработчики при замене полей.

Нативными остаются скрытый токен формы, скрытый input загрузки файла и кнопка
аварийного `app/global-error.tsx`: она должна работать при отказе общего layout.
Предметные карточки задач/событий и календарные сетки композиционно используют
базовые элементы; их бизнес-логику не переносим в `shared/ui`.

Проверки: `pnpm --filter web lint`, `pnpm --filter web typecheck`,
`pnpm --filter web test:ui`. Последняя проверяет HTML-семантику форм и композицию;
она не заменяет браузерную проверку размеров, тем, фокуса и взаимодействий.
