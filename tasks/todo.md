Статус: план, ни одна задача ниже ещё не выполнена. Концепция: [plan.md](./plan.md).
Пути новых файлов предварительные; использовать существующие соглашения проекта.
Каждая задача заканчивается рабочей проверяемой частью. Оценка — объём, не обещание сроков.

**Приёмка:**

- [ ] Без активной пары или с чужим petId доступ запрещён; имя валидируется; создание и переименование привязаны к ожидаемой паре/питомцу.
- [ ] Ответ содержит серверное время, версию и доступные действия; история ограничена курсором.

**Проверка:** `pnpm --filter api test --runTestsByPath src/pet/pet.service.spec.ts`;

## 7. Уход с мгновенной реакцией

**Результат:** команды на экране, короткие реакции, оптимистичное состояние с откатом.

**Приёмка:**

**Проверка:** браузер: успешный уход, offline во время отправки, 500, потерянный ответ,

## 8. Синхронизация партнёров

**Результат:** действия отражаются на втором устройстве; разрывы соединения восстанавливаются.

**Приёмка:**

- [ ] `pet.updated` отправляется обоим участникам только после commit.
- [ ] Возврат в приложение и reconnect восстанавливают актуальное состояние без ежесекундного polling.
- [ ] Старая версия события не перезаписывает новую; чужие пользователи не получают состояние.

**Проверка:** два браузерных контекста, смена сети, свернуть/вернуть PWA, серия событий

## 9. Разрыв и смена пары

**Результат:** питомец прежней пары недоступен после разрыва и не попадает в новую пару.

**Приёмка:**

- [ ] Команда, одновременно пришедшая с разрывом, не обходит проверку членства.
- [ ] Оба клиента очищают старый кеш после уведомления/перепроверки членства; старые запросы ухода, создания и переименования не применяются к новой паре.
- [ ] Архивные данные сохраняются; создание новой пары не переносит их автоматически.

**Проверка:** интеграционный сценарий leave/write race, два открытых клиента,
разрыв пары → новая пара → возврат старого запроса; регрессия existing relationship flow.
**Зависимости:** 8.
**Файлы:** `apps/api/src/relationship/relationship.service.ts`, `apps/api/src/pet/pet.service.ts`,
`apps/web/features/pet/model/use-pet.ts`, `apps/web/features/relationship/hook/use-relationship.ts`,
`apps/api/test/pet.integration.ts`.
**Объём:** средний, 5 файлов. Для уведомления можно использовать существующий relationship.updated.
