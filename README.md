# niDio

**niDio** — это современное прогрессивное веб-приложение (PWA) для пар, созданное для совместного управления задачами, общением и организацией общего пространства. Проект разрабатывается с использованием лучших современных технологий фронтенда и бэкенда, чтобы обеспечить быстрый, безопасный и удобный опыт для пользователей.

---

## 🚀 Введение

niDio — это платформа, которая помогает двум людям строить отношения, делиться задачами, общаться и работать вместе в едином цифровом пространстве. Проект ориентирован на простоту, безопасность и расширяемость. Уже сейчас реализованы базовые модули для аутентификации, приглашений, создания рабочих пространств и обмена данными.

---

## ⚡ Ключевые возможности (уже реализовано)

- **Next.js 16** — современный фреймворк для фронтенда
- **NestJS** — мощный серверный фреймворк на Node.js
- **Prisma ORM** — удобная работа с базой данных
- **PostgreSQL** — надёжная СУБД
- **FSD (Feature-Sliced Design)** — структурирование фронтенда
- **Аутентификация** (регистрация, вход)
- **JWT** — безопасные токены доступа
- **Refresh-токены** — обновление сессии через httpOnly cookies
- **Модуль отношений и приглашений** (создание пары, инвайты)
- **Создание рабочих пространств** (workspace)
- **Базовые UI-компоненты** (Button, Input, PasswordInput, AuthLayout, Link)
- **React Hook Form + Zod** — валидированные формы
- **TanStack Query** — асинхронные запросы и кэширование
- **Axios API-клиент**

## 🏛️ Архитектура проекта

Проект разделён на отдельные приложения и сервисы:

| Папка/Модуль | Описание                                     |
| ------------ | -------------------------------------------- |
| `apps/web`   | Фронтенд на Next.js (интерфейс пользователя) |
| `apps/api`   | Бэкенд на NestJS (REST API, бизнес-логика)   |
| `prisma`     | Модели данных, миграции, Prisma Client       |
| `postgres`   | Контейнер с PostgreSQL (через Docker)        |

### Схема бизнес-потока

1. **Регистрация** пользователя
2. **Создание приглашения (Invite)** для второй половинки
3. Второй пользователь переходит по ссылке-приглашению
4. **Принятие приглашения** — формируется пара (Couple)
5. **Создаётся общее рабочее пространство (Workspace)**
6. Оба пользователя взаимодействуют в едином пространстве

## ⚙️ Установка и запуск (шаг за шагом)

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/your-org/nidio.git
   cd nidio
   ```

2. **Установите зависимости:**

   ```bash
   pnpm install
   ```

3. **Запустите PostgreSQL через Docker:**

   ```bash
   docker compose up -d
   ```

   (Убедитесь, что порт 5432 свободен)

4. **Настройте переменные окружения:**
   - Скопируйте пример `.env.example` в `.env` и заполните необходимые значения для web и api.

5. **Примените миграции и сгенерируйте Prisma Client:**

   ```bash
   pnpm prisma migrate deploy
   pnpm prisma generate
   ```

6. **Запустите оба приложения для разработки:**
   ```bash
   pnpm dev
   ```
   (или отдельно: `pnpm --filter web dev` и `pnpm --filter api start:dev`)
