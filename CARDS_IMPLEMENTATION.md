# Карты Nidio — 23 октября 2026

## Реализовано

- Общая коллекция «Наши карты» с количеством, поиском по магазину/номеру/категории (пробелы в поиске номера не мешают), категориями, избранным и сортировкой по последнему открытию.
- Цветные карточки с нейтральными инициалами магазина и маскированным номером; пустое состояние с действием и сброс поиска/фильтров.
- Одно нажатие открывает код: полный экран на телефоне, центрированный диалог на компьютере. Чёрный код на белом фоне независимо от темы, свободные поля, выделяемый номер, копирование, редактирование, подтверждение удаления.
- EAN-13, EAN-8, Code 128 и QR. Контрольные суммы EAN проверяются клиентом и сервером. Code 128 ограничен 80 печатными ASCII-символами. QR сохраняет исходное содержимое. Неизвестный формат не превращается в выдуманный код; доступен номер и имеющееся фото.
- Screen Wake Lock с освобождением при закрытии и повторным запросом при возвращении на вкладку. Сообщение об удержании экрана показывается только после успешного запроса. Приложение не обещает управлять системной яркостью.
- Добавление: камера, локальное распознавание изображения или ручной ввод. Камера включается только по нажатию; потоки останавливаются при выходе и скрытии вкладки. Ошибки доступа не блокируют ручной сценарий.
- Короткая форма: магазин, номер, исходный формат. Категория, цвет, фото, комментарий и избранное — в дополнительных полях. Ошибка сохранения не очищает форму; повторная загрузка фото использует уже созданную карту.
- Предупреждение о совпадающем номере и серверный запрет точного дубликата магазина/номера/формата внутри пары.

## Архитектура и файлы

Сохранены существующие LoyaltyCard, FinanceProvider, авторизация, FinanceAccess, защищённое хранение фотографий и событие finance.updated. Данные хранятся в PostgreSQL; фотографии — через существующий StorageService. Мутации ограничены coupleId и транзакцией существующей архитектуры. Отдельная база, локальная имитация синхронизации и миграции для карт не потребовались.

## Ограничения проверки

Камера реального телефона, распознавание фотографии через системный выбор файла, чтение кассовым сканером, внешний S3, полный цикл копирования с проверкой буфера и остальные темы не проверены вручную. Код этих сценариев реализован; их нельзя считать подтверждёнными аппаратными тестами. Совместный доступ проверен интеграционно, а не двумя физическими телефонами.

В локальной коллекции оставлена тестовая карта «Проверка карт Nidio» (EAN-13 4006381333931). Существующие пользовательские карты не изменялись и не удалялись. Удаление проверено на одноразовых данных интеграционного теста.

## Обновлённый сценарий добавления и предъявления

По следующему запросу пользователя сценарий упрощён:

- Добавление сразу открывает название и цвет, затем три действия: камера, галерея, ручной ввод. Формат пользователь не выбирает.
- Сканирование сохраняет обнаруженный формат. Для ручного ввода выбирается EAN при корректной контрольной сумме, Code 128 для коротких печатных идентификаторов, QR для ссылок и остальных данных. По одному номеру невозможно достоверно восстановить исходный формат: это выбор подходящего представления, а не гарантированное распознавание оригинала.
- Предъявление содержит только код/номер, закрытие и переключатель QR/штрихкод (если линейное кодирование возможно). Альтернативный QR кодирует те же данные; его приём зависит от оборудования магазина.
- Редактирование перенесено на карандаш карточки каталога, удаление — в форму редактирования с прежним подтверждением.
- Переворот занимает 250 мс, использует CSS transform и существующий motion-токен. При reduced motion переворот отключён. Размер области кода одинаков для QR и штрихкода.
- Дополнительно использован skill animate. В Chrome проверены порядок полей, ручной ввод без выбора формата, оборот карты и переключение QR. Тесты автоматического выбора формата, типы и сборка прошли; аппаратная проверка камеры остаётся открытой.

## Единый фильтр категорий

В форме создания/редактирования добавлен выбор категории с иконками. В каталоге категории и сортировка заменены одним списком «Все / Избранное / категории»; «Все» является фильтром, а не сохраняемой категорией. Избранное фильтруется по isFavorite. Из лицевой стороны карточек убраны инициалы и маскированный номер. Используется переиспользуемый IconSelect на установленном Base UI. Проверены typecheck, lint изменённых файлов, UI-тесты; в Chrome — список с иконками, фильтр избранного и сброс фильтра.
